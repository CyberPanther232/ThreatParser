{# ── What is ThreatParser ─────────────────────────────────────────── #}
What is ThreatParser?

ThreatParser is a free, open-source email analysis tool designed to help individuals and security teams quickly identify phishing attempts and unsolicited bulk email (spam). Upload a raw .eml file and ThreatParser will inspect its headers, embedded URLs, and attachments, producing a human-readable threat report in seconds.

{# ── Why I built it ───────────────────────────────────────────────── #}
Why I Built It

Phishing emails remain one of the most effective attack vectors in cybersecurity. I built ThreatParser to give non-technical users a simple, no-setup-required way to inspect suspicious emails without forwarding them to a third-party service or needing specialist knowledge. The goal is to make defensive email analysis accessible to everyone.

{# ── Features ─────────────────────────────────────────────────────── #}
Features
  • Header analysis — SPF, DKIM, DMARC, Reply-To mismatch, and bulk-mail header detection.
  • URL extraction & classification — heuristic detection of phishing, tracking, and file-download URLs with file type labelling (image, archive, executable, script…).
  • Attachment scanning — flags dangerous file extensions commonly used to deliver malware.
  • VirusTotal integration — optional live URL lookup against the VirusTotal database (requires a free API key).
  • Dual scoring — separate phishing and spam scoring tracks produce a nuanced verdict: PHISHING, SPAM, MIXED, or CLEAN.
  • REST API — programmatic access via POST /api/analyze with optional API key authentication and built-in rate limiting.
{# ── Disclaimer ───────────────────────────────────────────────────── #}
Disclaimer
ThreatParser is provided for educational and defensive purposes only. Results are based on heuristics and should not be considered a definitive security verdict. Always exercise caution with suspicious emails and consult your organization's security team when in doubt. No email data is stored or transmitted by this tool beyond any optional VirusTotal API calls you initiate.
